- Independent review (two-axis: standards + spec) findings addressed in a follow-up revision: the scrolling-mode and forced-colors evidence above (previously asserted from existing suites, now run and recorded), the shared `CustomColorPill` + `customSnapshotFields` extractions (one spelling each), a "deliberate test-only seam" comment on the raw-IndexedDB e2e helper, and the `CONTEXT.md` Highlight-slot vocabulary extension. Declined with rationale: renaming the `bases` prop (taste-level churn across 8 files) and bundling the customColor+tint pair into a type (the pair IS the domain — snapshot + derived paint — and the shared helper already gives it one spelling).
- Implementation evidence notes: the settings panel's slot editors now mount only while the panel is open (each editor carries a live preview `<mark>`; an always-mounted hidden preview would shadow the reader marks in every document-wide `mark.highlight` locator — the remount costs nothing because every editor value lives in the settings record). The reference CI gate (`e2e-reference`) owns the comprehensive functional run for the PR.
