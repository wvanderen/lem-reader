## Linux-WebKit lane observations (recorded honestly, never excluded)

1. `page-turn-focus-handoff.spec.ts` — the four button-originated cells fail on
   Linux WebKit exactly as documented in `docs/setup.md` (2026-11-04, #254
   verification): Linux WebKit keeps focus on the activated button where the
   macOS/Safari signature assumes it falls to body. Lane divergence evidence;
   the macOS reference gate owns those cells.
2. `footnotes.spec.ts "an oversized note crosses repeated continuations without
omissions"` — one sampled note label (160) missing on container WebKit.
   **Reproduced on a clean origin/main worktree** (`/tmp` worktree at a21084d,
   same container lane: 1 failed / 10 passed), so it is a pre-existing
   main-condition, independent of this branch (this branch's diff is
   test-only: two long-work cells + one local script). Classification pending
   the macOS reference gate on this PR: if macOS WebKit passes the cell, this
   is a third documented Linux-WebKit divergence; if macOS also fails, it is a
   genuine footnote-continuation defect to fix before release. Recorded here
   rather than excluded anywhere.
