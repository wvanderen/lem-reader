## Visual evidence

The slot browser spec captures `desktop-slot-toolbar.png`, `phone-slot-toolbar.png`,
and `phone-slot-panel.png` under each browser's Playwright `test-results` folder.
Desktop and 320px phone captures were inspected together: long names remain within
the toolbar and panel; the focused panel button stays visible. These are browser
captures, not DOM-emulator layout assertions.

## Failure semantics

Slot application remains two field writes with best-effort compensation. If a newer
tag edit supersedes the application, its tags are retained and the original color
failure still reaches the existing failure surfaces. This fix does not claim that
two independent writes form an atomic transaction.
