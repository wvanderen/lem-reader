# Wayfinder visual world replaces Soft Paper

The "Soft Paper" system — warm cream surface, warm brown accent, system-serif stacks — was the deliberate Phase-1 answer to "calm and booklike," but the cream-plus-serif pairing had become the category's default look rather than a choice. A deliberate design-system round (concept-seed hand e6e028dc, seven grounded directions, six catalog challengers) replaced it with the Reading Room Wayfinder: the app styled as library wayfinding signage — enamel bottle-green boards with white spaced caps own the chrome so the article can be the brightest, quietest panel; layout, information architecture, and all accessibility mechanics are unchanged. The user pinned this direction over the roll's assigned card-catalog direction.

We also ended the zero-web-fonts posture for the reading voice: one self-hosted reading serif serves the article body while chrome uses a self-hosted public-wayfinding humanist sans. The pagination engine already awaits `document.fonts.ready`, so font-settling repagination stays inside the existing contract; the cost is a bounded download budget, accepted because the body face is the reader's entire visual world.

Considered and declined: the assigned Card Catalog direction (annotation-first but retro-office risk), a Tabbed Manual (board hues shout during long reading), a Destination Blind (industrial register), a Patent Sheet (diagram-first energy), and the category standard played straight (indistinguishable by design). Theme names become Daylight (default), Warm paper, and Night; the internal `light`/`sepia`/`dark` setting values are unchanged, so persisted reader settings survive untouched.
