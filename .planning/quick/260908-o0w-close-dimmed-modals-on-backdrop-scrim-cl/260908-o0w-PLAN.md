Wire backdrop-scrim click dismissal into all nine dimmed modal dialogs.

Purpose: Readers expect clicking the dimmed area around a modal to dismiss it — the
dialog prop-docs already promise "cancel button (or Esc / scrim)" but no click
listener exists anywhere. Browsers do NOT auto-close a native modal dialog on
::backdrop clicks; it must be handled explicitly per dialog.

listener-registration useEffect (structural-clone discipline — no shared abstraction),
routed through the same close prop its Cancel/Esc path uses; focused component tests
for the two representative semantics; one small real-browser e2e spec.
</objective>

Verified detection semantics (do NOT re-derive): every modal dialog element has
`padding: 0` and its visible content lives in an `*-inner` child wrapper, so the
dialog's border box == the visible card/sheet. A click on the dimmed ::backdrop is
therefore exactly a click whose event.target === the dialog element. Clicks on
visible content always target descendants. This works in Chromium/Firefox/WebKit.

CRITICAL close-path discipline (the 09-06 open-prop mirror rule in the file
comments): the browser must NEVER close the dialog from the scrim path. A scrim
click calls the SAME handler the dialog's Cancel button / Esc path uses
(onClose/onCancel → parent flips the open prop false → the existing sync effect
calls dlg.close()). Never call dlg.close() directly from the click handler — a
stale open=true prop would wedge the dialog shut.

Deliberately OUT of scope (zero changes): src/routes/review/ReviewNoteDialog.tsx
and src/reader/annotations/NotePopover.tsx (transparent ::backdrop by design —
no dimmed affordance, commit-on-close semantics); src/reader/TocPanel.tsx and
src/reader/SelectionToolbar.tsx (non-modal popovers, no backdrop).
