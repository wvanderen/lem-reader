Implement the inline round-trip anchor gate (SC#1) — every successfully ingested article MUST pass 5-offset `deriveQuoteSelector` → `resolveQuoteSelector` → `confident` before it's returned; an article that can't round-trip is REFUSED, not admitted to the library. Purpose: This is the integration truth of the phase (SC#1). The orchestrator owns the pipeline ordering, the immutability contract (save-once via slugifyUrl id), and the honesty contract (three-state confidence → refused / low-confidence / confident). The round-trip gate is the load-bearing assertion that an ingested article is treatable identically to a fixture for the annotation machinery.

Output: `server/ingest.ts` (the platform-agnostic orchestrator), real `tests/unit/server/normalization.spec.ts` (SC#1 phase-exit gate).

    Imports: `import { safeFetch, type FetchedContent } from "./safeFetch";`, `import { extractAndNormalize } from "./htmlToBlocks";`, `import { deriveConfidence, type ConfidenceResult } from "./confidence";`, `import { slugifyUrl } from "./slugify";`, `import { IngestionError } from "./errors";`, `import { ArticleSchema, type CanonicalArticle } from "../src/content/schema";`, `import { normalizeText, graphemeClusters, deriveQuoteSelector, resolveQuoteSelector } from "../src/content/normalizeText";` (Pitfall 2 — reuse exactly), `import { createHash } from "node:crypto";`, `import type { IngestionRequest, IngestionResponse, IngestionFailureReason } from "../src/ingestion/types";`.

    Export `function assertRoundTripAnchor(article: CanonicalArticle): void`. Implementation per RESEARCH.md §Pattern 4 L326-344:
    1. `const total = graphemeClusters(normalizeText(article), article.lang).length;`
    2. Build 5 sample offsets: `[0, Math.floor(total * 0.25), Math.floor(total * 0.5), Math.floor(total * 0.75), Math.max(0, total - 32)]`.
    3. For each `start`: `const end = Math.min(total, start + 20); if (end <= start) continue;` (skip degenerate ranges).
    4. `const selector = deriveQuoteSelector(article, { start, end });` (uses default contextRadius=32).
    5. `const resolved = resolveQuoteSelector(article, selector, { start, end });`
    6. If `resolved !== "ambiguous" && resolved !== "orphan"` → continue (success — either a confident TextPositionSelector object returned, or the original position reaffirmed). Else throw `new IngestionError("round-trip-anchor-failed")`.

    Note: `resolveQuoteSelector` returns `TextPositionSelector | "ambiguous" | "orphan"` per src/content/normalizeText.ts L174-179. The gate considers ANY non-confident resolution a failure (Pitfall 2 — the integration truth).

    Export `async function ingest(input: IngestionRequest): Promise<IngestionResponse>`. Implementation per RESEARCH.md §Pattern 1 L249-279:
    1. Validate input: if `(!("url" in input) && !("html" in input)) || ("url" in input && "html" in input)` throw `new IngestionError("server-error")` (exactly one of url/html required).
    2. Try-block: `let html: string; let finalUrl: string | undefined; let origin: "url" | "paste"; let fetchedAt: string | undefined;`
    3. If `"url" in input`: `const fetched: FetchedContent = await safeFetch(input.url); html = fetched.html; finalUrl = fetched.finalUrl; origin = "url"; fetchedAt = new Date().toISOString();`
    4. Else: `html = input.html; finalUrl = undefined; origin = "paste";`
    5. `const { blocks, footnotes, lang, provenancePartial, isReaderable } = await extractAndNormalize(html, finalUrl);`
    6. Build the article object: `const id = slugifyUrl(finalUrl ?? `paste-${shortHash(html)}`);` (paste path derives id from a content-prefixed hash since there's no URL).
    7. `const originalHtmlHash = "sha256:" + createHash("sha256").update(html).digest("hex");` (V6 — SHA-256 traceability).
    8. `const assembled = { id, revision: 1, lang, provenance: { ...provenancePartial, retrievedAt: new Date().toISOString(), originalHtmlHash }, blocks, footnotes, ingestionMeta: { source: origin === "url" ? "url" : "paste", origin, sourceUrl: finalUrl, originalHtmlHash, fetchedAt, extractionConfidence: "high", extractionWarnings: [] } };` (extractionConfidence placeholder; updated below).
    9. `const article: CanonicalArticle = ArticleSchema.parse(assembled);` (Zod-at-boundary — V5 input validation + Pitfall 5 URL scheme guards fire here).
    10. `assertRoundTripAnchor(article);` (SC#1 — refuses entry on ambiguous/orphan. MUST run AFTER ArticleSchema.parse so the gate receives a validated article.)
    11. `const confidence: ConfidenceResult = deriveConfidence(article, { isReaderable });`
    12. If `confidence.state === "unsupported"`: return `{ ok: false, reason: "extraction-unsupported" }` (ING-06 — no silent garbage into the library).
    13. Stamp the confidence onto the article: `article.ingestionMeta = { ...article.ingestionMeta, extractionConfidence: confidence.state === "confident" ? "high" : "low" };` (mutation is safe here — the article is local to this request, not yet persisted).
    14. Return `{ ok: true, article, confidence: { state: confidence.state === "confident" ? "confident" : "low" } }`.

    Wrap steps 2-13 in a try-catch: `catch (e) { if (e instanceof IngestionError) return { ok: false, reason: e.reason }; // log e server-side; return generic for non-IngestionError return { ok: false, reason: "server-error" }; }`. The catch ensures every refusal path produces a typed IngestionResponse the edge function can serialize.

    Add a small `function shortHash(s: string): string { return createHash("sha256").update(s).digest("hex").slice(0, 12); }` helper for the paste-path id.
