## Phase Goal

**As a** reader, **I want to** create, revisit, and manage local highlights and notes, **so that** they remain attached to their intended normalized text across every view change.

> This plan (05-02) delivers the **first end-to-end vertical slice**: select text → floating toolbar → capture to durable anchor → persist → render `<mark>` INTO the existing renderer → re-render from anchors on every relayout. After this plan a real reader can create a highlight in EITHER mode and it stays put through repagination, mode switch, and reopen. Notes/drawer/navigate/delete (Plan 05-03) and ambiguous/orphan surfacing (Plan 05-04) layer onto this slice.

<objective>

Purpose: This is the ANNO-01 "create in either mode" + ANNO-05 "survives relayout" + ANNO-06 "canonical anchors" slice. Output: 3 new UI files, 3 modified renderer/route files, 1 CSS modification, 1 component test.
