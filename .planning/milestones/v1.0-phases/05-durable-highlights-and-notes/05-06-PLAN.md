<objective>
Close the Phase 5 UAT Test 11 BLOCKER (pagination uneven pages) by gating the
page-geometry read on the `.paginated-surface` class, and add the CI regression
guard the debug session explicitly flagged as missing.

Purpose: On initial article load in paginated mode (the default), ArticleView's
geometry effect's first requestAnimationFrame fires while the SCROLLING branch
is still mounted (trustedView is null on the first render), so it reads the
scrolling-body natural height (~1148–1313px) and the first pagination pass packs

MODE SWAPS, not on initial load where paginated is the default from the start.

eac0845); it was masked by a racy ~0.5–0.9s downstream correction AND a fooled
no-overflow e2e. Phase 5's measurement-selector change is exonerated (returns
the correct 8 measurement-body blocks with correct heights). This fix unblocks
ANNO-05 (highlights remain attached across repagination) whose Test 10/11 proofs
were observed in the uncorrected/partially-corrected state. The underlying
layout contract being re-verified is Phase 4 PAGE-03 (even, viewport-sized pages).

Output: A one-line gate in ArticleView's geometry effect + a dedicated
real-browser regression spec that captures the FIRST pagination publication and
asserts even distribution.
