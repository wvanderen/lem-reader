## Phase Goal

**As a** reader, **I want to** move predictably through complete responsive pages and switch or fall back to scrolling without losing my logical passage, **so that** I can read long-form content in a calm booklike way while retaining stable orientation.

This plan delivers the **pagination engine** — the pure domain logic that turns Phase 3's trusted `MeasurementResult` into explicit source-range page fragments. It is the load-bearing substrate every later plan renders and navigates.

<objective>
Build the project-owned pagination engine as a pure domain module under `src/pagination/` (STACK.md mandate; NOT CSS columns, NOT Paged.js). The engine consumes Phase 3's `MeasurementResult` + a DOM `Range.getClientRects()` line-box pass to compute contiguous, non-overlapping source-range page fragments covering the article exactly once in canonical order, applying D4-01 booklike line-splitting, D4-02 atomic/splitting classification, D4-03/D4-04 widow rules, and D4-fallback termination guards (75% oversize, 300-page ceiling, zero-progress stall).

Purpose: This is the highest-risk requirement in the prototype (PAGE-03 exactly-once/no-clipping/no-duplication/nontermination). The engine is pure, deterministic, and unit-testable with jsdom HTMLElement stubs carrying mocked `getClientRects()` — no React, no persistence (persisting derived page boundaries is FORBIDDEN per STACK.md).

Output: Five new modules in `src/pagination/` + four Vitest unit specs proving the engine's contracts before any UI consumes them.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fixture/article model → engine | Article blocks cross from Zod-validated fixture data into the engine; the engine trusts the model shape (already Zod-validated at repository load) |
| DOM (Range.getClientRects) → engine | Browser layout output is read into LineBox[]; a browser quirk could yield unexpected rect counts (mitigated by Playwright cross-engine proofs in Plan 05) |
| engine → DiagnosticBus | Fallback events cross into the diagnostic substrate that Plan 05 surfaces to the reader |
