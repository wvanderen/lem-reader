## Phase Goal

**As a** reader, **I want** any fast text-measurement path to be proven trustworthy against real browser geometry before it is enabled and to self-correct if it drifts, **so that** invisible miscalibration can never silently degrade the layout I rely on.

## Plan Purpose

Promote Pretext from absent to the calibrated PRIMARY measurement path for eligible block kinds (D3-03), with the evidence PAGE-08 demands: a Playwright harness that measures Pretext's predicted `{ height, line breaks }` against rendered DOM across the 6 shipped fixtures × the typography matrix × Chromium/Firefox/WebKit, a committed per-engine fingerprint artifact that CI diffs (D3-10), and a runtime drift guard that downgrades a kind Pretext→DOM if it drifts at runtime (D3-08). Builds on Plan 03-01's engine, types, and diagnostics; refines the engine's per-kind dispatch from DOM-only to Pretext-where-eligible.

Output: a calibrated fast path with CI-enforced regression proof, plus the runtime self-correction that a primary fast path requires.
