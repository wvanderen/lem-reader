## Phase Goal

**As a** reader, **I want to** read and resume articles in a calm scrolling view with adaptable typography, theme, and recoverable local preferences, **so that** the reading experience matches my access needs and I never lose my place.

> Phase 2 is split into three vertical slices (plans 01/02/03). This plan (01) delivers the **adaptable reading surface** — the live-apply settings panel + quiet persistent header. Plan 02 adds persistence + STATE-05 recovery; Plan 03 adds location restore + quiet progress.

<objective>
Deliver the app's first persistent chrome (a slim quiet header) and first user-mutable visual layer (typography + theme via CSS custom properties) as a live-apply settings panel built on native `<dialog>`/`showModal()`.

This plan establishes the frozen-contract substrate (Zod settings/location schemas, Dexie `version(2)`, the `applyTheme` token writer, the React `SettingsContext`) AND the interactive panel that lets a reader change font family, text size, reading width, spacing preset, and theme — seeing each change applied live behind the panel. Settings are held in-memory in the context; Dexie persistence is deferred to Plan 02 (the context exposes the seam Plan 02 fills).

Purpose: This is the foundational vertical slice — every later Phase 2 capability (persistence, location restore, progress) mounts on the schema, context, header, and CSS custom properties established here.
Output: Working settings panel + header; green schema/context/panel tests; green Playwright a11y suite (panel-keyboard focus trap+restore per Pitfall 1, reflow, forced-colors, reduced-motion, touch-targets).
</objective>
