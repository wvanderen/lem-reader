> Visual and interaction contract for the **non-modal table of contents** (ORNT-01,
> ORNT-03, ORNT-04, ORNT-05) and the **passive restoration marker** (ORNT-06).
> Generated by `gsd-ui-researcher`, verified by `gsd-ui-checker`. Phase 18 adds one
> header icon trigger, one non-modal panel surface, one transient marker, retires
> the ResumeBanner across 4 surfaces, and resolves the one open geometry decision
> (5th header button at narrow widths). Every piece either reuses an existing
> token/pattern verbatim (quiet-button anatomy, tag-popover seam, `.status`
> announce discipline, D5-11 jump tail) or extends `src/app.css` additively.
> Zero new packages; zero store changes; zero routes.

## Component Inventory

All components are **additive, extraction, or retirement**. Existing visual surfaces are reused unchanged unless flagged.

### NEW: `src/content/toc.ts` (pure derivation — ORNT-04)

Not a visual component. `deriveToc(article) → TocEntry[]` walks `article.blocks`: every `heading` block with `level 2–6` becomes `{ text, offset: blockStartOffsets[i], blockIndex, level, depth }`; skipped levels deepen `depth` WITHOUT invented intermediate entries; duplicate texts pass through AS-IS (D18-10/D18-11). Zero persistence, zero DOM (Pitfall 9 — no Dexie changes).

### NEW: `TocPanel.tsx` (non-modal panel — ORNT-01/03/04/05)

- **Anatomy:** container `<div popover="manual" class="toc-panel">` holding `<h2 class="toc-title">Contents</h2>` + `<nav aria-label="Table of contents">` with a nested `<ul>` of `<a>` entries. The first entry is the synthetic **"Top of article"** (offset 0, depth 0, targets the article h1 — D18-09). **NO `role="dialog"`, no `aria-modal`** (D18-01; the NotePopover VoiceOver blocker forbids claiming dialog semantics on a non-modal surface).
- **Entries:** real `<a href="#toc-{blockIndex}">` — activation intercepted via `preventDefault` (hash router NEVER re-parses; Pitfall 4). Fragment-only hrefs are defense-in-depth (the shipped fragment guard blocks them from `setView`). Heading text renders as React text children (auto-escaped).
- **Current entry:** exactly one entry carries `aria-current="true"` — mapped from the shared scroll-spy's current heading `data-block-index`; before the first heading, the Top entry carries it (D18-12).
- **Internal scroll:** the panel owns its scrolling (`overflow-y: auto`); on open it scrolls internally to bring the `aria-current` entry into view **by computing `offsetTop`/`scrollTop` on the panel element — NEVER `scrollIntoView`** (which would scroll ancestor pages; D18-15's no-page-side-effects rule).
- **Headingless state (D18-13):** the list renders only "Top of article" plus the note `This article has no headings.` below the title — honest empty state, same chrome.

### NEW: `RestorationMarker.tsx` (passive transient cue — ORNT-06)

- **Visual:** a 4px solid `--accent` bar, absolutely positioned (zero layout impact — ORNT-06 forbids content shift), `border-radius: 2px`.
  - Scrolling mode: attached to the restored block, `inset-inline-start: calc(-1 * var(--space-md))`, height = the block's rendered height (sits in the main padding gutter — visible at every width ≥320px).
  - Paginated mode: attached to the restored **page** (the page fragment containing the restored offset), 4px bar on the page's inline-start edge, page-height — D18-05's "restored page edge".
- **Announce:** on mount, a visually-hidden `<div role="status" aria-live="polite" aria-atomic="true">Returned to where you left off.</div>` — the ResumeBanner announce discipline verbatim.
- **Lifecycle (D18-07/08):** mounts ONLY when a reopen-restore actually landed (a saved location existed and was restored — never on first open with no location, never on TOC jumps, never on Highlights deep-links). At 3400ms the bar gains `.is-fading` (a 600ms CSS `opacity` transition); at 4000ms it unmounts. Under `prefers-reduced-motion` the global gate kills the transition — the bar clears as an instant/step state change (Pitfall 8 — CSS-only, zero JS animation code). No dismissal interaction exists.

### NEW: `src/reader/sectionSpy.ts` (extraction — not a fork)

SectionAnnouncer's detection (IntersectionObserver + rAF-throttled passive scroll fallback + 250ms debounce over the 48+8px sentinel rule) extracted with a **heading-selector parameter**. SectionAnnouncer consumes `"h2, h3, h4"` (announce contract byte-stable); TocPanel consumes `"h2, h3, h4, h5, h6"` (Pitfall 5). One implementation, two parameterizations (D18-12).

### EXTENDED: `Header.tsx` (5th article-scoped trigger — D18-02)

- **Trigger:** `<button class="toc-trigger" aria-label="Table of contents" aria-expanded>` FIRST in the article-scoped group → Reader reads `[contents][tags][annotations][mode][gear]`. Anatomy mirrors `.tags-trigger` byte-for-byte: `min-height/min-width: var(--touch)`, `padding: var(--space-sm)`, transparent bg + 1px transparent border, `border-radius: 4px`, `--ink-soft` rest, `--accent` on `:hover` and ONLY when `[aria-expanded="true"]`, global 2px `:focus-visible` ring, 20px inline-SVG glyph (`pointer-events: none`). ## Interaction Contract

Phase 18 inherits the global interaction rules (READ-04 calm chrome, A11Y-06 reduced-motion gate, A11Y-07 44px touch, A11Y-05 forced-colors, global `:focus-visible` 2px ring, always-underlined links) **without modification**.

1. **The panel is non-modal — no trap, ever (D18-01/D18-04).** No focus trap, no inert backdrop, no `role="dialog"`/`aria-modal`. Tab from the panel's last entry flows into the page naturally; Tab from the page can reach the panel; Esc always closes. True at rail AND full-width-sheet geometry — even when the sheet visually covers the page, the page behind stays keyboard-escapable.
2. **One close seam (RESEARCH Pattern 1).** The open state is a React prop synced to `showPopover()`/`hidePopover()`; a single `toggle` listener is the ONLY close path — trigger toggle, Esc, entry activation, and (sheet mode) outside-pointerdown all route through `hidePopover()` so the seam fires state-reset + focus-restore exactly once. No second focus-restore path.
3. **Manual Esc is hand-added.** `popover="manual"` gets no native light dismiss — a keydown handler on the open panel (and the trigger) routes Esc through `hidePopover()`. The ONLY hand-rolled key handling in this phase.
4. **Outside-click policy is width-scoped (OQ4).** Wide (≥640px rail): outside clicks do NOT dismiss — the panel is a persistent reading companion (D18-01 "slides beside the article content"). Narrow (≤639px sheet): `pointerdown` outside the panel (and outside the trigger) closes it — the calm escape when the page is covered. Both route through the one seam.
5. **Open/close changes nothing logical (ORNT-05).** Opening or closing the panel never scrolls the page, turns a page, moves the canonical location, fires repagination, or disturbs the reading surface. The panel is fixed-position overlay geometry ONLY — it never resizes the article column (Pitfall 7: no ResizeObserver-triggered repagination from panel geometry). At wide widths pointer events on the page beside the panel pass through naturally (the panel occupies its own bounds, no full-viewport shield).
6. **Entry activation = close + jump + focus (D18-03).** `preventDefault` on click/Enter; the panel closes (through the seam); the mode-aware D5-11 tail runs — scrolling: `findScrollTarget` → `scrollIntoView({block:"start"})`; paginated: `fragmentContainingOffset` → `turnToPage`; then `tabIndex={-1}` programmatic focus on the destination heading element via `[data-block-index]` (rAF + 120ms firefox-settle guard, the shipped D4-07 discipline). The destination heading carries a visible focus cue via a `.toc-destination:focus-visible` outline rule (2px `--focus-ring`, offset 2px — the global ring, guaranteed for programmatic focus). Modified/middle clicks fall through to the harmless same-document fragment.
7. **"Top of article" targets the article start.** Offset 0 → scrolling scroll-to-top / paginated page 1; focus lands on the article h1 (the D14-03 `articleH1Ref` precedent).
8. **`aria-current` discipline (D18-12).** Exactly one entry carries `aria-current="true"` at all times, derived from the shared section-spy (`h2–h6` selector for the TOC; the announcer keeps `h2–h4` byte-stable — Pitfall 5). Above the first heading, the Top entry carries it. Visual reinforcement = weight 600 + 2px underline thickness, never color alone.
9. **Open-where-you-are (D18-15).** On open, the panel scrolls internally (offsetTop/scrollTop math, never `scrollIntoView`) to bring the `aria-current` entry toward the vertical center. Zero page-level scroll side effects.
10. **Focus on open lands in the panel (A4 resolved).** Opening moves focus to the `aria-current` entry (or first entry when none) — SR/keyboard readers land where they are, not stranded on the trigger. Closing returns focus to the trigger on EVERY path (D18-01) — the toggle seam owns this.
11. **Marker honesty (ORNT-06 / D18-08).** The marker + announce fire ONLY when a reopen-restore genuinely landed: a saved location existed AND the restore resolved. First open with no saved location → no marker, no announce (never claim a restore that didn't happen). TOC jumps communicate via focus-on-heading (rule 6); Highlights deep-links keep today's behavior. One cue per cause — no double-signaling.
12. **Marker never interferes.** Absolutely positioned (zero layout impact — no content shift, no reflow); never blocks page turns or pointer events (`pointer-events: none` on the bar); auto-clears at 4s (600ms CSS opacity fade from 3400ms); under reduced-motion the global gate makes the clear instant (Pitfall 8 — CSS transition only, zero JS animation).
13. **Restore in BOTH modes (sanctioned gap closure).** Paginated reopen-restore + paginated save-on-turn close in-phase (§Auto-Resolved #8) so the marker is honest in the default reading mode. A reader who turns pages persists a location (debounced anchor-change save + dual flush); a paginated reopen lands on the saved page with the marker at its edge.
14. **Hash router untouched (Pitfall 4).** TOC entries are intercepted links; `parseHash` and the fragment guard stay byte-stable; the TOC adds NO routes — panel state is transient, never a destination; `history.replaceState` only, never hash assignment.
15. **Reduced motion (A11Y-06).** Zero new transition/animation/scroll-behavior properties except the single marker opacity fade — a CSS transition auto-killed by the global gate. Panel open/close is an instant state change (mount/unmount), matching every shipped overlay.
16. **Forced colors (A11Y-05).** Current entry = `aria-current` + weight/stroke; the marker bar maps to `CanvasText`; the announce carries the semantics — no color-only cues anywhere.
17. **StrictMode idempotency.** Open-state sync + restore/marker effects use previous-value comparison (the shipped one-shot-effect patterns); twin-mount runs are byte-identical.
18. **View change closes the panel.** Navigating away (Back to library, shell nav, another article) closes the TOC through the seam — the panel never persists across destinations and never appears in history.

### The ≤639px five-button geometry decision (Pitfall 6 / OQ3 — SANCTIONED)

**Measured constraint (RESEARCH, chromium 320×640 Reader):** the current 4-button row has ~10px slack; a 5th 44px trigger + gap needs ~50px → **~40px deficit**. Controls group needs ≈254px (5×46 + gaps + padding); with shell-nav ≈122px the row cannot fit below **≈378px** viewport width. The Phase 15 relief ladder (padding/gap trims only, 44px floor, one 48px row) is exhausted.

**Sanctioned relief — staged destination collapse scoped to Reader:**

At `max-width: 420px` AND `.app-header[data-destination="reader"]`, the `.shell-nav` links receive the shipped `.visually-hidden` clip treatment (the wordmark's ≤639px mechanism, same declarations — `position: absolute; width/height: 1px; clip: rect(0 0 0 0)` — NEVER `display: none`). **Additionally** (strengthen-only, applies to the collapsed wordmark too): a `:focus-visible` rule un-clips the collapsed links so a focused destination link becomes visible — sighted keyboard users are never left on an invisible focus target (latent Phase 15 gap closed in passing).

**Why this relief (rejected alternatives):**
- **(a) two-row 48px wrap — REJECTED:** a 96px header at the wrap breakpoint breaks the load-bearing 48px constants (`main.paginated-main` `calc(100dvh − 48px)`, banner `top` offsets, `restoreLocation.ts` `headerPx = 48`, SectionAnnouncer 48+8px sentinel) — JS constants would become width-dependent, touching byte-stable modules and pagination geometry at exactly the narrow widths where the D6-09/D6-10 edge invariants run. Also violates the Phase 15 locked rule "The 48px height NEVER changes."
- **(b) shorter shell-nav labels — REJECTED:** copy churn with the weakest a11y return (RESEARCH).
- **(c) sub-44px buttons — REJECTED:** the touch floor is not negotiable (A11Y-07).
- **Sanctioned (staged collapse):** keeps the single 48px row + every load-bearing constant byte-stable; keeps all five 44px targets; everything stays in the a11y tree and tab order; the visible Library affordance in Reader at extreme narrow is redundant by design — `Back to library` sits at the content head (D15-04), and Highlights is one hop away once back. D15-17's "no vanishing destinations" intent bends ONLY below 420px in Reader, where D18-02's locked 5th button makes the row arithmetically impossible — and bends with reachability + focus-visibility preserved.
- **420px chosen** ≈44px headroom above the measured ≈378px crossover, absorbing engine font-metric variance; 320px (WCAG reflow), 375px (SE-class phones), and 400% zoom (1280→320 effective) all collapse; 390px+ keeps links visible where the row still fits.

**Mandatory e2e (toc-geometry.spec):** at 320×640 Reader — the row neither wraps nor overflows nor silently overlaps (`.header-start` `flex-shrink: 0` keeps deficits visible — the 15-04 honesty fix); all five buttons ≥44px; the collapsed destinations remain keyboard-reachable AND render visibly on `:focus-visible`; D6-09 `assertEdgeInvariant` + existing reflow/touch-target/high-zoom suites join unchanged.
