# Phase 20 — UI Design Contract

> Visual and interaction contract for **safe local image fidelity** (IMG-01…06).
> Generated by `gsd-ui-researcher`, verified by `gsd-ui-checker`. Phase 20 is a
> low-chrome phase with ONE new visual surface: the **figure placeholder**
> (D20-14) — a quiet framed box + image glyph + alt text that is the SAME
> surface for refused-at-ingest, legacy-remote, and broken-at-read figures —
> plus reserved-geometry rendering for accepted local images (`<img>` in an
> aspect-correct box whose size is known BEFORE decode) and one new honest
> warning string in the import preview. Everything else is behavior under
> byte-stable chrome: ingest pipeline, Dexie v6, bundle v4, cascades. No new
> controls, no new routes, no new dialogs, zero new packages in `src/`.

## Typography

Phase 20 reuses the existing typography roles **without modification**. No new sizes, no new weights, no new line-heights.

| Role | Size | Weight | Line Height | Phase 20 usage |
|------|------|--------|-------------|----------------|
| Placeholder note | 14px | 400 | 1.45 | `Image unavailable.` — the `.meta` chrome register (`--font-ui`, NOT italic: it is not a caption) |
| Placeholder alt text | 14px | 400 | 1.45 | Visible alt text inside the placeholder — same register; alt is content in this state, so it renders as plain readable text |
| Caption | 14px | 400 | 1.45 | `figcaption` register (`--font-ui` italic, `--ink-soft`) — byte-stable in EVERY figure state (D19-01 marks untouched) |
| Reading body / headings | unchanged | 400 / 600 | 1.6 / 1.2–1.3 | Figures sit inside the unchanged reading rhythm |

**Two weights only:** 400 (regular) + 600 (semibold), project-wide rule. The placeholder uses NO emphasis weight — a refused figure is an honest calm state, not an alert.

**Alt-text visibility rule (locked):** in the accepted state, alt is the `<img>` `alt` attribute (invisible, SR-only — as today). In every placeholder state, alt renders as VISIBLE text inside the frame (it is the recoverable content — D20-06). The `img`/alt surface renders no marks ever (D19-02); visible placeholder alt text is likewise unmarkable and unselectable-as-highlight — it is inside the media box, not the caption.

## Component Inventory

All components are **extended or pure-derived** except the placeholder surface, which is new styling on an existing element kind. No new block kinds (D20-06), no new routes, no new dialogs.

### EXTENDED: `BlockRenderer.tsx` figure case (the ONE render change)

- **Accepted state:** `<img src={objectUrl} alt={block.alt} width={block.width} height={block.height} loading="lazy" decoding="async" onError={…}>` + inline `aspect-ratio: <w>/<h>` from the stored dims (RESEARCH Pattern 4 — inline style is the primary mechanism; the width/height attributes are belt-and-suspenders). `onerror` swaps to the placeholder INSIDE the same reserved box — geometry from the model never changes (Pitfall 5).
- **Every non-asset state (refused → no `src`; legacy row → remote `httpUrl` src; broken → asset row missing):** the placeholder `<span class="figure-placeholder">` — NO `<img>` element is emitted (a remote `src` NEVER reaches an `<img>` — IMG-03 by construction). Reserved box: stored dims when present (broken), the `--figure-placeholder-ratio` default when absent (refused/legacy).
- **Caption:** the existing `figcaption` + InlineList + `captionHighlightSlices` path renders BYTE-IDENTICALLY in every state (D19-01).
- **`elementProps`/`data-block-index` forwarding unchanged** — pagination's 1:1 block↔element mapping is untouched.

### NEW: `AssetProvider.tsx` (resolution context — not a visual component)

Per-article object-URL map at ArticleView scope (RESEARCH Pattern 4): fixture-registry consult first (fixtures never touch Dexie), `db.assets.bulkGet` second; missing rows render as the broken placeholder state. Owns the full `createObjectURL`/`revokeObjectURL` lifecycle — revoke-all on articleId change/unmount (Pitfall 9); a unit test asserts create/revoke symmetry. Both bodies (scrolling + hidden measurement body) render from the ONE stable map — no per-turn create/revoke churn, no async gap where a figure renders before its URL exists.

### NEW: `.figure-placeholder` CSS (app.css — the ONE new visual surface)

Quiet framed box: `background: var(--surface-raised); border: 1px solid var(--hairline); border-radius: 4px; padding: var(--space-md)` (the `.disclosure`/`.status` chrome class), `display: flex; flex-direction: column; align-items: center; justify-content: center; gap: var(--space-sm); text-align: center`, reserved geometry per §Layout. Contents: the 20px inline-SVG image glyph (`aria-hidden="true"`, `--ink-soft`) above the visible alt text (or the note when alt is empty). Plain `<span>` semantics — the visible text is the accessible content; NO `role="img"`/`aria-label` (would duplicate the visible text for SRs); no focus, no tabIndex (not interactive).

### NEW: figure media geometry CSS (app.css — reserved boxes)

`.article-body figure > img` gains `display: block; max-width: 100%; margin-inline: auto; max-height: var(--figure-media-max-h); object-fit: contain` — the first `img` rule in the stylesheet (none exists today). Inline `aspect-ratio` per figure from the model. See §Layout for the cap constants.

### EXTENDED: `ImportPreviewDialog.tsx` (ONE additive warning entry)

The existing `import-preview-warnings` list gains the dangling-asset entry (§Copywriting) when the no-broken-refs gate skips articles. Anatomy, KIND_LABELS, overrides, per-item metadata disclosure, single-`onProceed` Pitfall-8 call site, `[data-initial-focus]` on Cancel import — all byte-stable. Asset conflicts ride article-record conflicts (D9-14 semantics) — NO new ConflictKind, NO new row, NO new choice.

### EXTENDED (invisible): persistence, portability, ingest

`db.ts` v6 `assets` store, `LibrarySource.save/remove` + `booksStore` cascade extension, `bundle.ts` v4 + `ExportImportService` asset entries + no-broken-refs gate, `server/` asset stage + `fetchImageAsset` + EPUB container extraction — zero visual surface. The RemoveConfirm / BookRemoveConfirm / WipeConfirm destructive copy stays BYTE-STABLE and truthful: the asset cascade extends beneath the same "everything about this article is removed" semantics (D17-13 shape).

### REUSED unchanged (surface-stable)

`figcaption` register + caption marks · `AddDialog` 3-way picker + pending/refusal spine (inline asset fetching lengthens latency; the EXISTING pending state carries it — zero new Add chrome) · `PaginationFallbackBanner` (fires less often, not more — the media cap keeps figures under the oversize threshold) · `PageIndicator`/`PageTurnControls`/`ProgressHairline` · TOC/annotations/tags header triggers · Settings export/import buttons · hash router (zero new routes; object URLs are never location values).

### NEW chrome strings (verbatim — e2e anchors)

| Element | Copy |
|---------|------|
| Placeholder note (empty-alt figures only) | `Image unavailable.` |
| Import-preview dangling-asset warning (1) | `1 article will be skipped because its images aren't included in the bundle.` |
| Import-preview dangling-asset warning (n) | `{n} articles will be skipped because their images aren't included in the bundle.` |

Register matches: the note follows the Phase 18 full-sentence note register (`This article has no headings.`); the warning follows the existing preview-warnings register (`2 highlights will import as ambiguous.`) — count + plain-word noun + honest predicate, plural agreement honest. "Asset", "reference", "dangling", "bundle entry" are internal vocabulary and must not appear.

### Carried-forward anchors (byte-stable — regression targets)

| Element | Copy |
|---------|------|
| DOC-06 disclosure summary | `Some content from the original article isn't supported yet.` (stays for genuinely unsupported blocks — tables/math/embeds/PDF figure regions) |
| Caption content | alt + caption text render as-is from the canonical model — never re-truncated, never re-cased |
| Import dialog | `Import this bundle?` · `Import` · `Cancel import` · `Apply imported reading preferences` · KIND_LABELS family |
| Destructive confirms | RemoveConfirm / BookRemoveConfirm copy byte-stable (cascade extends invisibly) |

**Primary CTA mapping:** none new — the phase is passive rendering. The retry path is re-ingest through the EXISTING Add flow (D20-07); no in-reader retry affordance exists, so no CTA copy exists.

**Empty state:** none new — the placeholder is a CONTENT state (a figure with honest fallback), not an empty state. Library/review empty states are byte-stable.

**Error state:** the placeholder IS the calm failure surface (D20-14) — one surface for ingest refusal, legacy remote refs, and read-time decode/missing-blob failure. No reason taxonomy is rendered: WHY a figure was refused is provenance/diagnostic data; WHAT the reader sees (alt, caption, the note) is the honest disclosure. The article-load error path (`The article could not be loaded…`) is untouched.

**Destructive actions:** none new. Existing confirms stay truthful as the asset cascade extends beneath them.

## Interaction Contract

Phase 20 inherits the global interaction rules (READ-04 calm chrome, A11Y-06 reduced-motion gate, A11Y-07 44px touch, A11Y-05 forced-colors, global `:focus-visible` 2px ring) **without modification**.

1. **Decode is paint, never layout (D20-13 / IMG-06).** The figure box is fully determined by the model (stored dims → `aspect-ratio` + attributes; refused/unknown → the default ratio box) BEFORE any byte decodes. Image load, decode, and error events cause ZERO layout shift — page-count identity across image load is a mandatory e2e assertion (geometry.spec), and the canonical location never moves because repagination never re-triggers from image events.
2. **One surface, three non-asset states (D20-14).** Refused-at-ingest (any limit: type/SVG/animated/bytes/pixels/count/budget), legacy remote-src row, and broken-at-read (missing blob row, `onerror` decode failure) render the IDENTICAL placeholder. `onerror` swaps the accepted `<img>` for the placeholder INSIDE the same reserved box — the box never resizes on failure.
3. **The renderer never contacts a host (IMG-03).** Only `asset:` refs resolve through the provider's object-URL map; a `src` that is not a resolvable local asset renders the placeholder BY CONSTRUCTION — there is no code path from a remote URL to an `<img src>`. The offline e2e route-abort guard makes any accidental fetch a test failure.
4. **Nothing moves on its own (D20-09).** Animated images refuse at ingest; nothing in the accepted set animates. Zero new `transition`/`animation`/`scroll-behavior` properties on any Phase 20 selector — reduced-motion is satisfied trivially; state changes (error → placeholder) are instant swaps.
5. **Figures are static content.** No zoom/lightbox, no click-to-enlarge, no retry button, no affordances (D20-07; OQ3's no-lightbox call). The figure surface is NOT focusable and NOT a touch target — it adds nothing to Tab order; keyboard reading order = document order is preserved (DOC-02).
6. **Caption marks are state-independent (D19-01).** The figcaption renders the same inline `<mark>` anatomy in every figure state; the D-05 substrate (alt + caption joined by BLOCK_SEPARATOR) is byte-identical under the src rewrite — saved locations, highlights, and caption anchors are untouched by construction (mandatory unit assertion).
7. **Alt discipline is state-driven.** Accepted: `alt` attribute (SR-only, as today). Placeholder: visible text (it IS the content). Empty alt + placeholder: the `Image unavailable.` note. Empty alt + accepted: `alt=""` stays valid (decorative image, caption carries meaning). The note NEVER replaces non-empty alt.
8. **Lazy + async decode only on real images.** `loading="lazy" decoding="async"` on accepted `<img>`s; the hidden measurement body's figures keep stable geometry from CSS (reserved boxes), never from decode — measurement is image-load-independent in both bodies (the whole point of D20-13).
9. **Object-URL lifecycle is provider-owned (Pitfall 9).** One map per open article; revoke-all on articleId change/unmount; StrictMode twin-mount runs are byte-identical; a unit test asserts create/revoke symmetry. Page turns mount/unmount fragments WITHOUT creating or revoking URLs.
10. **Per-figure refusal never blocks the article (D20-05).** One bad image refuses alone; the article saves normally. The reader sees the figure survive as alt + caption + placeholder — in-band honest disclosure; no toast, no dialog, no Add-flow chrome (extractionWarnings stays a data channel this phase).
11. **The media cap protects pagination (Pitfall 3).** `max-height` + `object-fit: contain` letterboxing keeps every figure box under the atomic-oversize threshold — a panorama letterboxes calmly rather than triggering dom-fallback for the whole article. Letterbox areas show plain surface; inspectability loss at narrow widths is the accepted OQ3 trade-off (no lightbox this phase).
12. **Import honesty (IMG-04 / Pattern 6).** Dangling asset refs → per-article skip + the preview warning (never silent placeholder-rewrite on import). Identical article + assets = calm no-op; incoming-wins replaces asset rows in-transaction; skip writes nothing. Orphan asset entries drop inertly. Asset bytes never conflict independently of their article (content-hash ids).
13. **Forced colors (A11Y-05).** The placeholder frame → `CanvasText`; glyph + text inherit foreground; the figure state reads by shape (frame + glyph + text + caption), never color-alone.
14. **44px touch (A11Y-07).** No new controls; nothing shrinks. Existing targets byte-stable.
15. **Byte-stable chrome everywhere else.** Header, TOC, annotations, pagination chrome, Add dialog, settings — untouched. The phase changes what figures ARE, not where anything sits.

```
 │ └──────────────────────────────────────────────────────────────────┘
 │ …prose…                                                            │

Paginated twin: the SAME figure renders inside page fragments (ATOMIC —
 never split); reserved boxes make measurement stable pre-decode; the
 media cap keeps figure+caption under the 0.75 oversize threshold.

  Constants (NEW — the only new custom properties, both geometry):
    --figure-media-max-h:      calc((100dvh - 48px - 2 * 48px) * 0.5)
    --figure-placeholder-ratio: 3 / 2
  where 48px = load-bearing header height, 2 * 48px = paginated page
  block insets (--space-2xl). The media box may occupy at most HALF the
  paginated page content box, leaving ≥ 25% headroom under the Phase-04
  0.75 atomic-oversize threshold for caption + margins at the smallest
  supported viewport (320 × 640 reflow standard: cap = 248px; a 3:2 box
  at the 288px column = 192px — the ratio binds before the cap).
  In scrolling mode the same value is a calm viewport-relative ceiling.

  Corpus tunability (IMG-02 mandate): the planner may tune the ratio and
  relax/tighten the 0.5 factor DOWNWARD from corpus evidence; the CEILING
  rule is fixed — figure total (media + caption + margins) must stay
  under 0.75 × page content height at 320 × 640, or the oversize fallback
  fires (the exact destabilization IMG-06 forbids).
```
