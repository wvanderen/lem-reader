## 1. Refinement Contract — Tag menu anchoring (POLISH-08)

**Behavior locked by D21-05; technology chosen by probe evidence**
(RESEARCH Pattern 1 — CSS anchor positioning verified on this project's
pinned Playwright 1.61.1 chromium/firefox/webkit; zero JS listeners).

The menu **hugs its trigger**:

| Clause | Contract |
|--------|----------|
| Adjacent on open | Opens directly below the `.tags-trigger` header button, separated by exactly `margin: var(--space-xs)` (4px calm gap) |
| Viewport-kept | Fully inside the viewport at any width ≥240px via `position-try-fallbacks: flip-block, flip-inline` — no manual clamp math |
| Geometry-following | Repositions under the trigger on resize, reflow, and zoom with ZERO JS listeners — browser-owned via anchor resolution |
| Focus restore | Any close path (Esc, light-dismiss, toggle) returns focus to the trigger — existing toggle-event seam (ArticleView); e2e-asserted, no new code |
| Interaction contract | `popover="auto"` byte-stable: top layer, light-dismiss, Esc. `role="dialog"` + `aria-label="Article tags"` unchanged |
| Motion | Zero motion properties (static repositioning; reduced-motion gate trivially satisfied) |

**CSS shape (replaces the `app.css` L1949–1959 fixed block wholesale):**

```css
.tags-trigger { anchor-name: --tags-trigger; }
.tag-popover {
  position: fixed;                     /* insets now resolve vs the anchor */
  position-anchor: --tags-trigger;
  position-area: block-end span-inline-end;
  position-try-fallbacks: flip-block, flip-inline;
  inset: auto;                         /* kill UA popover insets (MDN conflict note) */
  margin: var(--space-xs);
  /* width: min(420px, calc(100vw - 2 * var(--space-md)))  — cap unchanged */
  /* padding/border/background/radius unchanged: --space-md / hairline / surface-raised / 4px */
}
/* DELETE: top: calc(48px + var(--space-xs)); inset-inline-end: var(--space-md); */
```

Hard rules: author insets (`top`, `inset-inline-end`) MUST be deleted, not
zeroed alongside `position-area` (RESEARCH Pitfall 2 — they fight anchor
resolution). `TagEntry` internals byte-unchanged; only the mount's geometry
moves. TocPanel (`popover="manual"`) and native `<dialog>` surfaces are
untouched — their contracts are locked (D18).

## 2. Refinement Contract — Truthful reading width (POLISH-09)

**"The far-right endpoint never lies" — 64 means 64** (D21-01/D21-04).

| Property | Contract |
|----------|----------|
| Steps | `MEASURE_STEPS = [40, 46, 52, 58, 64]` ch — uniform step 6 (keeps the shipped `step` arithmetic); default stays 64ch (array index shifts 2→4) |
| Slider attributes | `min=40`, `max=64`, `step=6`; `aria-valuemin=40`, `aria-valuemax=64`, `aria-valuenow={value}` — visual and programmatic ranges identical |
| Readout | `Reading width N ch` — shape unchanged, no endpoint labels (D21-04) |
| Truth criterion | At far-right: `.article-body` content width equals a 64-"0"-advance ruler of the body font within 1px, in BOTH modes (scrolling `max-width: var(--measure)`; paginated `width: var(--measure)`), and readout + `aria-valuenow/max` all say 64. `ch` = the "0" glyph advance (css-values-4) — never verify by counting prose characters (RESEARCH Pitfall 4) |
| Legacy 72 | Pre-parse bounded map `{72: 64}` at the three seams (settingsStore read, settingsMirror read, import-preferences) + the `index.html` paint hint (no 72ch flash). SILENT — no prompt, no copy (D21-03). ONLY 72 maps; any other invalid value still fails parse → existing corrupt path (never-silently-coerce holds) |
| Schema | measure union drops `z.literal(72)` — only AFTER the clamp seams exist (RESEARCH Pitfall 1: deleting the literal without the clamp routes stored-72 readers to WipeConfirm) |

## 3. Refinement Contract — Highlights cohesion (POLISH-10)

Shared grid = **token conformance, not a literal shared grid template**
(D21-07). Highlights keeps its single-column row anatomy; every measurement
either conforms to the shared token or carries a citation comment (POLISH-07
discipline). Conformance ledger (rules enumerated by RESEARCH Pattern 3;
prescriptive calls below):

| `.review-*` rule | Library counterpart | Call |
|---|---|---|
| header/filter-row/legend/section `max-width: 1100px; margin-inline: auto` | `.library-list` family identical | Conforms already — no change |
| `.review-row` `padding: var(--space-md)` | `.library-row`/`.book-row` `--space-lg` | **CONFORM → `var(--space-lg)`** (primary-row register; the enumerated deviation candidate resolves as conform) |
| `.review-section h2` `font-size: 20px` | Library section h2 = global 22px register (`.continue-reading-strip h2` has no override) | **CONFORM — delete the override**, inherit global 22px/600/1.3 (resolves A5) |
| `.review-section-list` single column, `gap: var(--space-sm)` | `.library-list` 2/3-col responsive grid, `gap: var(--space-lg)` | **CITE — legitimate anatomy difference** (D21-07 keeps own row anatomy); citation comment required |
| No `@media` rules in review block | Library re-grids at 640/1024 | **CITE** — single column needs no re-grid; 1100px cap + `main#main` insets carry narrow widths |
| `.review-select` 16px | cited D15-03 intentional difference | **KEEP — existing precedent**, comment already in place |

**Visible row affordance (D21-06).** Every jump-capable (confident) row
carries a quiet open-in-reader glyph so the destination is understandable at
a glance:

- **Glyph:** north-east arrow (↗ "open in article context"), project anatomy
  exactly — 20×20, `viewBox="0 0 24 24"`, `fill="none"`,
  `stroke="currentColor"`, `stroke-width="1.75"`, round caps/joins,
  `aria-hidden="true"` + `focusable="false"` (TrashIcon/EditIcon clone).
- **Placement:** inside the `<button.review-row>` at the row foot,
  inline-end of the date line (SVG is non-interactive content — legal inside
  the button; the sibling `.review-row-actions` cluster is untouched).
- **Color:** inherits `--ink-soft` at rest; takes `--accent` on
  `.review-row:hover` (the quiet-chrome discipline — the glyph signals the
  jump, matching `.tags-trigger`/`.library-row-remove` rest/hover grammar).
  One additive selector, tokens-only, zero motion.
- **Rendering rules:** glyph appears ONLY on jump-capable rows — never on
  orphan-tail rows (no destination) and never on disabled/unresolved rows
  (ambiguous/orphan disabled rules unchanged, D21-06).
- **SR contract:** the `Go to highlight: …` `aria-label` is the whole
  accessible name — the glyph is decorative and adds nothing.
- **Back-to-Library:** the Phase 15 shell-nav Library link IS the direct
  path — no new back chrome, no breadcrumbs, no section-heading links
  (rejected, see CONTEXT deferred).

## 5. Acceptance-matrix UI criteria (ACPT-07 / ACPT-08)

No new UI ships; these are the visual/interaction bars acceptance asserts
over the four destinations (Library, Highlights, Add, Reader):

- **Keyboard:** every control reachable and operable by keyboard; Esc +
  focus-restore is the universal top-layer escape; engine focus divergence
  asserted honestly per engine (D18-04).
- **Reduced motion:** zero effective motion under `prefers-reduced-motion:
  reduce` — trivially true because the shipped UI (and this phase's deltas)
  declares no motion properties. Keep it that way.
- **Forced colors:** meaning survives by shape + name — highlight tri-state
  shapes, badge borders, link underlines, hairline chrome (incl. the
  re-anchored popover's border) all remain distinguishable.
- **Reflow:** no loss of content/function at 320 CSS px; the re-anchored tag
  popover stays fully in-viewport (flip fallbacks) at ≥240px.
- **Zoom:** 400% keeps all content and function — the new measure floor 40ch
  exists precisely for this; no horizontal-scroll traps beyond the reading
  surface's own measure.
- **Touch targets:** 44px minimum everywhere, including unchanged.
- **Core flow (ACPT-07):** one unbroken journey proven in chromium/firefox/
  webkit (D21-13); webkit image-save cells ride the five documented
  byte-stable skips (D21-11); real-Safari image truth via the D21-12 session
  folded into the VO+Safari run.
- **SR arms (ACPT-08):** human-run NVDA+Firefox and VoiceOver+Safari on
  protocol v1.3; flip only at zero blocker/major (D13-06/07). Protocol
  outcomes authored as role + accessible name + state — never verbatim SR
  phrasing (Pitfall 7).
