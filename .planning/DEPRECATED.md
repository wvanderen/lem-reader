# DEPRECATED — GSD planning artifacts

This directory contains planning artifacts generated by [GSD (get-shit-done)](https://github.com/glampsey/get-shit-done), which was **removed from this machine on 2026-09-12** and is no longer maintained or used.

These files are kept for historical reference only:

- `STATE.md`, `config.json` — GSD workflow state (no longer functional)
- `milestones/` — roadmaps, phase plans, summaries, and verification reports
- `PROJECT.md`, `RETROSPECTIVE.md` — project context captured by GSD

Do not expect any tooling to read or update these files. Task management for this project now goes through `td`.
